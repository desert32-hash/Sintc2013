개발사례

프로젝트_1 프로젝트_2
PROJECT NO. 01

무선 레일 이송 자동 제어 시스템 개발

컨셉 단계부터 현장 특성을 반영한 맞춤형 메커니즘으로 기획되었습니다.
바닥이 없는 현장 구조물에 맞춰 안정적인 주행이 가능하도록 하드웨어와 소프트웨어를 완전히 새롭게 설계하였으며,
무선 운용과 자동 제어 기능을 완벽히 구현하였습니다.

바닥이 없는 특수 구조물에서도 안정적인 주행이 가능하도록 하드웨어와 소프트웨어를 완전히 새롭게 설계했습니다.

컨셉 제안부터 설계, 제작, 제어 시스템 구축까지 전 과정을 수행하여 최적화된 레일 이송 자동화 시스템을 완성하였습니다.

컨셉 기획부터 무선 운용, 자동 제어 시스템까지 원스톱 구축

ISSUE 주요 문제점

  • X축 제어가 불안정하고 Y축 구동이 불가능함X축 제어 불안정·Y축 구동 불가
  • 설정한 속도와 실제 속도의 오차 발생
  • 자동 운전의 신뢰성이 낮음
  • 장비 상태를 확인하기 어려움
  • 전원을 끄면 현재 위치 정보가 초기화됨
  • 노이즈에 의한 제어 안정성 저하 가능성

REQ 고객 요구사항

  • 지정한 속도를 정확하게 유지할 것
  • X축과 Y축을 안정적으로 제어할 것
  • 속도 변경 기능 제공
  • 자동 및 수동 운전 지원
  • 무선으로 운용 가능한 시스템
  • 장비 상태를 쉽게 확인할 수 있는 화면 제공장비 상태 모니터링 화면 제공

핵심 해결 방안

01

레일 기반 이동 시스템 설계

바닥 없는 현장에 맞춘 공중 레일 주행 메커니즘

02

레일 오차 자동 보정 기능

±10mm 레일 간격 변화 자동 보정 및 주행 안정화±10mm 레일 간격 보정 및 안정 주행

03

전용 제어 PCB 개발

AVR 전용 PCB 설계 및 파이(π) 필터 EMI 차단

04

무선 배터리 구동

36V 배터리 적용으로 외부 전원 없이 무선 운용

05

X축·Y축 정밀 속도 제어

정밀 계산식 기반 코드로 목표 속도 유지

06

사용자 인터페이스 개선

LCD 화면을 통한 속도·거리·상태 실시간 표시

07

자동화 기능 추가

자동·수동·일시정지 및 비상정지(E-Stop) 구현

08

장비 진단 기능

배터리·LED·센서 상태 옵션 메뉴 즉시 확인

09

위치 복원 기능

FRAM 적용으로 전원 재투입 시 이전 위치 복구

STACK 적용 개발 기술

제품기획제품기획 기구 설계기구설계 레일 시스템 설계레일설계 전자회로 설계회로설계 PCB 설계기판설계 펌웨어 개발제어개발 모터 및 드라이버 선정모터선정 속도 제어 알고리즘속도제어 EMI 노이즈 대책필터설계 FRAM 데이터 저장자료저장 LCD UI 설계화면설계 무선 리모컨 제어무선제어

  • OK 목표 속도의 정밀 제어 구현
  • OK 자동·수동 운전 지원
  • OK 위치 복원 기능 구현
  • OK 현장 환경에 적합한 레일 이송 시스템 구축현장 맞춤형 레일 이송 시스템 구축
  • OK 레일 조립 및 설치 오차 자동 대응
